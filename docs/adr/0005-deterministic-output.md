# 产物必须逐字节可复现

## Status

accepted

## Context

自含压缩包内部要嵌入自身的尺寸与校验值，任何生成期噪声都会让产物哈希变化，导致回归测试只能靠解压后比对，分发时也无法用哈希复核。可能引入不确定性的来源包括：目录遍历顺序、生成时间戳、压缩器随机/并行行为、临时文件名泄漏进头部。

## Decision

同一份载荷（相对路径、内容、mtime 等元数据）加同一组参数，必须产出逐字节相同的产物。实现上必须：按相对路径稳定排序；不写入生成时间；压缩参数固定且不随运行环境变化；除源文件 mtime 外不引入任何时间源；不使用随机数。

## Considered Options

- 允许写入生成时间：便于溯源，但产物不可复现，测试与分发校验都变弱。
- 仅在 `--deterministic` 下保证：多一个开关，默认行为仍不可复现。
- 只保证解压结果一致：无法做产物级金标准测试。

## Consequences

- 产物中不会出现“生成于某时”的元数据；溯源信息只能来自载荷自身或外部记录。
- 回归测试可以直接比对产物 SHA-256。
- 修改源文件 mtime 也会改变产物，这是有意为之。
- 三种格式必须共享同一套排序与元数据规则，否则跨格式测试会漂移。
